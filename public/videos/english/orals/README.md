# WASSCE English Oral Exam Videos

This folder contains locally downloaded WASSCE English oral exam videos used by the Auntie Angel Oral English module.

- Source attribution is kept in `content/oral-videos.ts` (`sourceUrl`, `channel`, `youtubeId`).
- Verify rights/permissions before redistributing videos outside a personal/local study setup.
- Add captions/transcripts as `.vtt` files and reference them via `captionsSrc` in `content/oral-videos.ts`.
- `manifest.json` contains file sizes and SHA-256 checksums for integrity checks.
